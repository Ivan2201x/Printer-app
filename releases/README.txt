Descargas listas para usar
==========================

Windows
  GestorImpresionEscaneo.exe — doble clic (no requiere Python).
  Requiere impresora/escáner con drivers instalados en Windows.

Linux
  printer-app-linux.tar.gz — descomprimir y ejecutar install/linux/install.sh
  Requiere: python3, python3-tk, CUPS, SANE (scanimage).

Código fuente: raíz del repositorio (python main.py).
